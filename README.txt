ROOT — SESSION
===============

LANCEMENT
---------
Double-clique sur LAUNCH_ROOT.bat.
Le lanceur démarre un petit serveur LOCAL PowerShell sur 127.0.0.1:8765 puis ouvre ton navigateur.
Aucune installation de Python ou de Node.js n’est nécessaire.
Le serveur local est nécessaire pour que le navigateur puisse proposer l'autorisation webcam.

WEBCAM / CONFIDENTIALITÉ
------------------------
Les deux défis CamView utilisent l'API standard du navigateur (getUserMedia).
- Le navigateur demande l'autorisation au joueur.
- Aucun flux n'est enregistré.
- Aucune capture d'image n'est créée.
- Aucune vidéo n'est sauvegardée.
- Aucun flux n'est envoyé sur Internet.
- La caméra est coupée dès que CamView est fermé ou que le défi se termine.
- Si l'autorisation est refusée, l'histoire continue avec une variante.

Le reste du jeu (Internet, messages, fichiers, personnes, RootProject, menaces) est entièrement fictif et local.

CONTRÔLES
---------
Souris : ouvrir les applications, déplacer les fenêtres, répondre aux choix.
Double-clic : ouvrir une icône du bureau.
Échap : fermer une boîte de dialogue.

SAUVEGARDE
----------
Le jeu sauvegarde dans le stockage local du navigateur.
Le bouton CONTINUER du menu utilise cette sauvegarde.

IMPORTANT
---------
ROOT est maintenant un jeu d'horreur psychologique 100 % ordinateur.
Il n'utilise plus la maison 3D, SafeCam ni le monstre physique des anciennes versions.
